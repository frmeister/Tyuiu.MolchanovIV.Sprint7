	:: Описание проекта ::
По открытому файлу (структуризация файла, строго ограничена условиями описанными ниже), составленна программа которая предоставляет,
инфографику по представленным данным:

1) график с характеристиками автомобилей * ОПЦИАНАЛЬНО *
2) Таблицу водителей с их характеристиками
3) Таблицу с датами выездов и городов откуда и куда выехал водитель

	:: Стрктура программы ::
Приложение Windows Forms, подгружает данные из DataService и выводит информацию в графическом виде
при помощи gridView и chart

	:: Формат ввода ::

Автомобили:
Знак: {гос. номер}, марка: {марка автомобиля}, техническое состояние: {ужасно/плохо/хорошо/отлично}, местонахождение: {город из списка}, средняя скорость: {скорость}, грузоподъемность: {грузоподъемность}, расход: {расход топлива}
Водители:
Табельный номер {номер}, Фамилия: {фамилия}, Имя: {имя}, Отчество: {отчество}, Дата рождения: {дата}, Стаж: {стаж}, Оклад: {оклад}
Транспортная карта:
Дата выезда {дата}, Дата прибытия: {дата}, Место назначения: {город из списка}, Расстояние: {расстояние}, Расход горючего: {расход}, Масса груза: {масса}
